# Local media library

Добавляйте сюда медиафайлы для тестовых SIQ-пакетов. Всё содержимое каталога,
кроме этого README, игнорируется Git и не попадёт в pull request.

Рекомендуемая структура:

```text
media/
├── images/
├── audio/
├── video/
└── html/
```

В JSON-рецептах пути задаются относительно этого каталога, например
`"file": "audio/question.mp3"`. Абсолютные пути и `../` запрещены.
